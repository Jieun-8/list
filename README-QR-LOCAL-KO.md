# アイプリ・アイプリバース用カードアルバム（QR登録上限なし）

## この版で変更したこと
- アイカツ！アンコールの選択タイル・切り替えボタン・公式リンクを画面から削除。
- アイプリ／アイプリバースの既存カード一覧・画面デザインは維持。
- QRコード登録を原本サーバーに保存せず、このスマートフォンのブラウザの `localStorage` に保存。
- QRコードの固定50件上限をなくし、管理画面に「上限なし」と表示。
- カード登録数の集計からアイカツ！アンコールを除外。

## 重要な注意
- QRコードの保存はこのサイトを開いたブラウザ内のみです。別のブラウザや別端末とは同期しません。
- ブラウザの「サイトデータを削除」などを実行すると、ローカル保存したQRコードが消える場合があります。大切な記録は別途控えてください。
- **カード所持記録のログイン・同期機能は、原本の既存バックエンドを引き続き使用します。** その部分を完全なローカル保存に置き換えたものではありません。ログイン不要の完全ローカル版にするには、カード一覧の読み込みと所持記録・各種機能をまとめて移植する追加作業が必要です。
- QR登録の固定上限はありませんが、ブラウザの保存容量には上限があります。
- スマートフォンのカメラを使うには、HTTPSで公開したGitHub Pagesなどから開いてください。
