# アイプリ・アイプリバース・ワッチャプリマジ！カードアルバム（個人用カスタム版）

## この版の内容
- 原作の 2026-10-29 版をベースに、原作側の更新を反映。
- アイカツ！アンコールの切り替え・登録候補・共有画面の表示を除外。
- アイプリ／アイプリバース／ワッチャプリマジ！の既存カタログ・画面・関連機能を維持。
- カード・コーデ・パーツのQR情報は、サーバーではなくこのブラウザの `localStorage` に保存し、アプリ側の固定50件制限をなくした。
- QR管理画面にQR情報のバックアップ書き出し・復元を追加。
- 「自分のコーデ」ボタンから、コーデ名・メモ・画像・QRコードを手動登録できる機能を追加。カメラでQRを読み取り、保存したQRを再表示できる。手動コーデの情報もこのブラウザ内に保存され、バックアップ／復元に対応。

## データの保存について
- QR登録情報は `card-management-local-qr-v1`、手動コーデは `card-management-manual-coordinates-v1` という別々のブラウザ保存領域に保存する。
- 同じサイトの同じブラウザでファイルを更新する限り、保存キーと形式を維持しているため、通常は既存のQR情報はそのまま残る。
- ただし、ブラウザのサイトデータ削除、別のブラウザ・端末への移動、保存容量不足などではデータが失われる可能性がある。更新前にQR管理画面と「自分のコーデ」画面からバックアップを書き出すことを推奨。
- 「上限なし」はアプリ独自の件数制限を外したという意味で、ブラウザの保存容量そのものが無制限という意味ではない。
- セーブコード／フレカ、所持記録、ログイン、共有などは原作の既存サーバー機能を利用する。QRローカル保存や手動コーデはアカウント・別端末とは同期しない。
- カメラを使うには HTTPS で開き、ブラウザのカメラ権限を許可する必要がある。
